
## Аудит безпеки

1. Захист від XSS: перевірено всі використання innerHTML у js/script.js. Вивід повідомлення про помилку сервера у error-message переведено з innerHTML на textContent, решта динамічних даних також виводяться через textContent або автоекранування шаблонів Vue ({{ }}). У innerHTML залишилися лише очищення контейнерів (= '') і статична розмітка.
2. Локальні сховища (localStorage / IndexedDB): зберігаються лише нечутливі записи історії конвертацій (from, to, amount, result, timestamp) і прапорець міграції. Паролів, токенів чи персональних даних немає.
3. Секрети та HTTPS: у коді відсутні захардкоджені ключі й паролі. Для публікації застосунку обрано хостинг із HTTPS за замовчуванням (Vercel).
